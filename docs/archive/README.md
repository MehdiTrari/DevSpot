# Archive documentaire

Ce dossier sert à stocker les anciens documents qui ne sont plus actifs mais qu'il est utile de conserver.

## Exemple de contenus à archiver

- anciens TODO de chantier,
- plans intermédiaires devenus obsolètes,
- variantes de conception abandonnées,
- documents utiles pour retracer l'évolution du projet.

## Règle pratique

Si un fichier n'est plus une référence active mais garde une valeur historique ou pédagogique, il doit être déplacé ici plutôt que laissé à la racine de `docs/`.
