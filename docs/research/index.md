## Pourquoi séparer cette section

La documentation de recherche n'a pas toujours le même cycle de vie que la documentation produit :

- elle peut contenir des hypothèses,
- elle peut documenter des pistes non encore implémentées,
- elle reste néanmoins précieuse dans un contexte académique.

La séparer permet de garder une doc projet lisible sans perdre la valeur du travail de mémoire.
